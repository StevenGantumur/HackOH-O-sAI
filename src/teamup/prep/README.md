# Demo test prep bank

Open Team Up and choose **Practice problems**. `PrepBank.jsx` displays the three
Easy FastPrep listings summarized in `problems.js`, with search and selectable
details. Explore categories opens the same bank with a note about practicing
through that discipline; all three source questions are coding questions.

Titles, companies, and Easy labels were verified on the signed-in FastPrep pages
on October 24, 2026. Each entry links to its full source question. Prompts are
short summaries; examples and partner exercises are original demo content.
Solutions are not included. The catalog is bundled locally, with no scraping
at runtime, Supabase table, saved attempts, or completed-demo credit.

To add another entry, provide a unique `id`, title, company, difficulty, category,
topics, source URL, summary, example input/output, test cases, and partner exercise.
