# Capture checklist

Record a little longer than each final slot. The main script supplies the exact
narration, timings, captions, and the one-account fallback for collaboration.

## Prepare

- Start the app and sign in before filming the authenticated sections.
- Open a second confirmed account on the partner's device for live messaging/demo footage.
- Agree on a short test message so an unexpected private reply cannot enter the recording.
- Prepare the sample mission artifact and reviewer comments below.
- Use the sample Riley persona for the project workflow, Grace for its reviewer,
  and **Use my account** for real messages and live collaboration.
- Check whether the sample mission is still open. If already claimed/submitted,
  capture its current state or use a separate clean sample environment. Reset
  sample data only if the team is happy to lose those local changes.

## Prepared demo content

**Sample mission artifact:** A one-page interview guide with a consent introduction
and open-ended questions covering getting to a stop, waiting, and boarding. Use
an actual prepared file, not a link that pretends nonexistent work is complete.

**Sample reviewer feedback:** “The guide covers the whole trip and avoids leading
questions. Ask about a recent journey so riders can give concrete examples.”

**Coach request:** “Just do it for me.”

**Coach attempt:** “Here is my attempt: I would ask riders to describe a recent
trip, then ask where getting to the stop, waiting, or boarding became difficult.
How can I avoid leading questions?”

**Shared-document text, first user:** “For each index, calculate the operation
and compare it with the expected result.”

**Shared-document text, second user:** “Test empty arrays and subtracting a
negative number. Check that output order matches input order.”

## Final check

- Every clip represents an observed screen state, not a claim that a button worked.
- Live and sample labels stay consistent with the script.
- Real two-account demo footage is tested before recording, or the local-preview
  narration is used instead.
- Narration, captions, and screen results agree; feature text remains readable.
- The exported MP4 plays from beginning to end, stays within the submission size
  limit, and has no blank tail or accidental credentials in any frame.
